# Plot & Form 📚✨

Plot & Form es un generador de libros digitales que transforma ideas en publicaciones listas para Amazon KDP — combinando narrativa (plot) y estructura visual (form) para crear libros profesionales.

## Español

### 🎯 ¿Qué hace Plot & Form?

Genera **libros digitales completos** a partir de un simple texto descriptivo:

- 📿 **Libros de mandalas** para colorear y relajación
- 🐉 **Cuentos de fantasía** con ilustraciones
- 📖 **Historias noveladas** con narrativa coherente
- 🎓 **Libros educativos** con contenido didáctico
- ✨ **Y mucho más...**

**100% Gratuito** · **Sin APIs de pago** · **Contenido original** · **Listo para KDP**

### 🚀 Inicio Rápido

```bash
# 1. Clonar el repositorio
git clone https://github.com/mgdomm/Plot-Form.git
cd Plot-Form

# 2. Instalar dependencias
pip install -r requirements.txt

# 3. Iniciar la aplicación
python web/app.py

# 4. Abrir en tu navegador
# http://127.0.0.1:5000
```

## English

### 🎯 What is Plot & Form?

A **digital book generator** that creates complete, publication-ready books from simple text descriptions:

- 📿 **Mandala books** for coloring and relaxation
- 🐉 **Fantasy tales** with illustrations
- 📖 **Narrative stories** with coherent plot
- 🎓 **Educational books** with didactic content
- ✨ **And much more...**

**100% Free** · **No paid APIs** · **Original content** · **Amazon KDP ready**

### 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/mgdomm/Plot-Form.git
cd Plot-Form

# 2. Install dependencies
pip install -r requirements.txt

# 3. Start the application
python web/app.py

# 4. Open in your browser
# http://127.0.0.1:5000
```

### ✨ Features

- ✅ **Modern web interface** with comprehensive controls
- ✅ **Automatic content generation** from prompts
- ✅ **Code-generated geometric mandalas** (no external APIs)
- ✅ **Amazon KDP-ready PDFs** with correct margins
- ✅ **Interactive preview** with page navigation
- ✅ **In-line page editing**
- ✅ **Direct export** to PDF/EPUB

### 📁 Project Structure
